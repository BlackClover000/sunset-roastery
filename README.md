# محمصة الغروب | Sunset Roastery

موقع لمحمصة قهوة بنظام طلب تفاعلي، متجاوب بالكامل ويدعم العربية (RTL) والـ Dark Mode.

🔗 **Live Demo:** [https://blackclover000.github.io/sunset-roastery/]


## المميزات
- تصميم عربي RTL متجاوب مع الموبايل والكمبيوتر
- Dark Mode تلقائي
- سلة طلبات تحسب الإجمالي لحظياً
- استلام من المحل أو توصيل
- تحقق من البيانات (رقم موبايل مصري، الاسم، العنوان)
- Accessibility: ARIA وتنقل بالكيبورد

## التقنيات
HTML5 · CSS3 (Grid, Flexbox, Variables) · Vanilla JavaScript
